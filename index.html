humanlike-browser

Drive a real browser with human-like input — irregular mouse motion, no teleporting, move-before-click, natural typing — so Cloudflare Turnstile / "Verify you are human" checks and bot-flagged forms pass.

用拟人化输入驱动浏览器（不瞬移、不规则运动、移入再点、自然打字），让 Cloudflare Turnstile / 人机验证 与反爬表单能正常通过。

The rules that actually matter

  • Never teleport the cursor — always page.mouse.move(x, y, { steps }) first.
  • Irregular motion — random steps + pixel jitter; never the same curve.
  • Move → pause (~120–400 ms) → click.
  • 2–3 idle moves across the page before interacting.
  • Type with delays instead of instant fill.
  • Randomize timing; don't hammer on failure.

Scope & ethics

Use this for your own legitimate actions on services you're entitled to use — submitting your own form, testing your own site, accessibility/QA automation. Do not use it to bypass protections for scraping, abuse, or credential stuffing. Passing a bot check is not permission to do what the check was guarding. Prefer official APIs.
